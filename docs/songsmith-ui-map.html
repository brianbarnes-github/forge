Songsmith UI Map

Every named region of the current Songsmith GUI, numbered #1–#27 and #30–#33 (playback) to match docs/UI_GUIDE.md's naming table — so we're pointing at the same thing when you direct changes.

How to use this: click a number on the diagram, or a row in the legend below — the match highlights on both. teal markers are whole regions/containers; gold markers are specific controls inside them. Say "#16, the Part slot" and I'll know exactly where you mean.

Playback

30
Transport strip
TransportStrip
28 px, above the Songsmith view in the main window and at the top of the Track editor window: |< (go to start), << (back one bar), Play/Pause, Stop (back to where play started), >| (go to end). Space = Play/Pause.
31
Mute / Solo buttons
TrackRowComponent (M, S)
Right end of each non-conductor track row's info column. Session-only; they also govern what plays while the Track editor window is open.
32
Seek ruler
TimelineRuler
14 px strip above the main track canvas and above the Track editor's roll. Click or drag to move the playhead.
33
Playhead
PlayheadOverlay
Mouse-transparent vertical line over the note previews (main) or over the roll below the keyboard gutter (editor). The view page-flips to follow it while playing.

Not on the diagramMenus, context menus & drag-drop

These aren't fixed regions — they only appear on click/right-click/drag, so they're listed here instead of numbered above.

Menu bar contents

File New (Ctrl+N) → guarded Open… (Ctrl+O) → FileChooser, .songsmith; guarded Close → guarded Save (Ctrl+S) → disabled when clean with a path Save As… (Ctrl+Shift+S) Import ▸ MIDI… → FileChooser, .mid/.midi Export ▸ MIDI… / ABC… Quit Edit Undo / Redo → songDocument.undo()/redo() Song Default parts from tracks → synthesiseDefaultParts(songDocument) SoundFont… → FileChooser, *.sf2; path kept in settings Run Converter → runConversion(), shows the export panel View Export ABC panel → toggles the export panel (checkbox) Diagnostics list → toggles #23 (checkbox, unchecked by default)
